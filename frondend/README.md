# Tailor Lab - Premium Suit E-commerce

A responsive e-commerce website for Tailor Lab, featuring a modern and elegant design for premium suits, shirts, and trousers.

## Features

- Fully responsive design that works on desktop and mobile devices
- Modern UI with elegant typography and smooth transitions
- Collection showcase with categories (Suits, Shirts, Trousers)
- Featured products section
- "Why Choose Us" section highlighting unique selling points

## Technologies Used

- React.js
- React Bootstrap for responsive layout
- React Router for navigation
- Custom CSS for styling
- React Icons for social media icons

## Getting Started

### Prerequisites

- Node.js (v14 or higher)
- npm or yarn

### Installation

1. Clone the repository
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```

## Project Structure

- `/public/images` - Contains all images used in the website
- `/src/pages/customer` - Customer-facing pages
- `/src/assets/css` - Custom CSS styles
